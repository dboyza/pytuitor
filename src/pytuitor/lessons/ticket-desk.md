## Your first complete tool
A project combines things you already practiced.
Here you will read two answers, convert one to a number, make a decision, and print a useful result.
You already know everything needed to solve it.

## Practice in the workspace

Use the active exercise panel beside the editor for the current task requirements and input cases.
Run the program with values on each age boundary before checking it.
After Check passes, use the same habit on the Repair program: change one input at a time and observe which rule changes the result.
