## Practice: fuel stops
Define `travel(fuel, costs)`.
Visit the nonnegative integer costs in order.
Pay a cost only if fuel is at least that cost; stop at the first unaffordable cost.
Return the number of completed stops.
For `travel(8, [3, 4, 2])`, return `2`.
An empty list returns `0`; a zero-cost stop is affordable even with zero fuel.
Use a local counter, a loop, a condition, and `break`.
